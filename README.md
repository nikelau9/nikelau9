# Hi, I'm Unai Abascal Ruiz 👋

**Physicist & Electronics Engineer · Data Scientist for scientific and industrial data**

I turn complex laboratory, sensor and environmental data into reliable results and clear decisions.

and I am now focused on **data analysis, machine learning and AI applications** for industry.

- 🔬 **Background:** BSc Physics · BEng Industrial Electronics · MSc Nuclear Physics · PhD candidate (University of Seville)
- 📊 **Focus:** data analysis, anomaly detection, quality control analytics, ML pipelines, LLM / RAG applications
- 🌍 **Location:** Campo de Gibraltar, Spain · open to **remote** roles
- 🗣️ **Languages:** Spanish · Basque · English
